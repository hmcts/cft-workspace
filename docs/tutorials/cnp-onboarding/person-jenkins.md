# Jenkins

Jenkins login is managed through Microsoft Entra ID.

If a user cannot log in:

1. Check they are in the right [Microsoft Entra ID groups](person-entra-id.md#microsoft-entra-id-groups).
2. For most developers, this means `DTS CFT Developers` or `DTS SDS Developers`, plus any team-specific access group.

Team metadata and build dashboards are managed in [Jenkins](team-jenkins.md).
