# Azure

After [Microsoft Entra ID](person-entra-id.md) setup is complete, access [Azure portal](https://portal.azure.com/).

[Common access groups](person-entra-id.md#common-access-groups), such as `DTS CFT Developers` or `DTS SDS Developers`, give developers access to the standard Azure subscriptions they need.

Additional access to production subscriptions or other Microsoft Entra ID groups is based on use case.

Request additional access by creating a pull request in [azure-access](https://github.com/hmcts/azure-access).
