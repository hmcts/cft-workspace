# Cloud Native Platform onboarding

End-to-end onboarding for a new person joining a CFT or SDS team on the Cloud Native Platform.

Suggested order:

1. [Person onboarding](person.md) — the index for everything a new starter needs:
   - [Microsoft Entra ID](person-entra-id.md) — tenant accounts, guest invitations, access groups
   - [Azure](person-azure.md) — portal and subscription access
   - [VPN](person-vpn.md) — F5 VPN access and troubleshooting
   - [Slack](person-slack.md) — workspace access, profile, channels, GitHub-to-Slack mapping
   - [GitHub](person-github.md) — org access, SSO licence retention, troubleshooting
   - [Jenkins](person-jenkins.md) — Jenkins login access
   - [Developer tools](person-developer-tools.md) — Docker Business, first deployment, common tools
2. [Team — Azure AD](team-azuread.md)
3. [Team — GitHub](team-github.md)
4. [Team — Jenkins](team-jenkins.md)
5. [Team — Office 365](team-office365.md)
6. [Team — Slack](team-slack.md)
