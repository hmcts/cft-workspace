Documentation owned by the Developer Tools & Shared Services Engineering (DTSSE) /
Decentralisation team.

- [Work in progress](wip/README.md) — unreleased and exploratory platform work, written up early

  (`/dtsse:wip-add`, `/dtsse:wip-status`, `/dtsse:wip-promote`).

Settled DTSSE-owned platform behaviour lives in the product it belongs to — most
decentralisation material is under [`apps/ccd/docs/`](../../ccd/docs/README.md), starting with
[Decentralisation](../../ccd/docs/explanation/decentralisation.md).
